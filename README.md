# Transaction Ops Dashboard (Tableau)

Operations-style dashboard on sample payment/transaction data for enterprise BI practice (Barclays-style platform engineering prep).

## Live dashboard
https://public.tableau.com/app/profile/ronak.bhanushali/viz/TransactionOpsDashboard-BarclaysPrep/Dashboard1

- Amount by Region (bar)
- Status Mix — Completed / Failed / Pending (pie)
